# 国服 / 国际服英雄池与每队 0–5 Ban（PR #68 开发分支）

[返回文档索引](../README.md) · [比赛操作](operator-guide.md) · [识别与校准](screen-recognition.md)

## 功能和概念必须分开

在 Control → 比赛设置中独立配置以下选项：

1. **英雄池服务器**：国际服 `global`（原来的英雄名单、素材与稳定 ID）或国服 `cn`（独立候选目录）。切换后英雄选择器、服务器合法性验证、录像/赛后英雄 ID、模拟器可选英雄必须一致。
2. **每队 Ban 数量**：`0 / 1 / 2 / 3 / 4 / 5`，两队对称，各自都选 5 个英雄；不能将数字与服务器固定绑定。
3. **BP 模式**：`match` 在首轮最多 Ban 两名英雄/队，完成第一段 3 个 Pick/队后，再 Ban 剩余的 `banCount - 2` 个/队，然后进行末段 2 个 Pick/队；`normal` 在任何 Pick 之前把各队所有 Ban 一次完成。除 0 Ban 外，Match 模式标准 4 Ban 为 2+2，5 Ban 为 2+3。这里的社区赛自定义 0–3 Ban 顺序不是 KPL 官方专用赛制。
4. **跨局禁选限制**：普通（每局独立）、选手 BP（按选手 ID）、全局 BP（按稳定队伍 ID）；独立于 Ban 数。元流之子独立/共享形态规则保持原配置。

2026 年 KPL 规则文本的征召顺序为蓝红各 2 Ban → 双方各 3 Pick → 蓝红各再 3 Ban → 双方各 2 Pick，合计每队 5 Ban。官方国际赛事中的 Four-Ban Match 使用前 2 + 后 2 的流程，不能把“国际服”写死成永远只有四 Ban。参阅 [2026 KPL 征召规则](https://www.wangyoushe.com/info/Ejzlq) 与 [Honor of Kings 国际赛事规则](https://www.honorofkings.com/esports/kwc/rule.html)。**巅峰对决/Ultimate Battle 是双方盲选特殊流程，不等同于本系统普通 0 Ban 的公开顺序 Pick；当前尚未模拟巅峰对决的盲选。**

## 当前实现与安全边界

- 默认沿用国际服 Match 4 Ban；旧存档若无 `banCount`，按 Match=4、Normal=2 迁移，旧比赛有效局和 Undo 历史的英雄 ID 不做重编号。新比赛报告在提交时记录 `heroPool` 与 `banCount`。
- 国服候选使用独立 `src/data/cnHeroCatalog.ts`，目前仓库自带的**国服官方接口的 2026-08-19 存档（132 条）是工作快照，不能宣称 2026-10 国服所有英雄都已验证齐全**。国服独有英雄使用独立稳定 ID 范围（名字哈希）避免与国际服旧 ID 冲突；未取得真实头像时出现清晰的名称占位图，不冒充官方角色素材。当前客户端/后端可使用此目录完成**人工 BP**。
- 后续可在 `vite-project/` 运行 `npm run hero:cn-sync` 从国服官网 `https://pvp.qq.com/web201605/js/herolist.json` 拉取最新名单到版本受控文件；脚本要求格式与数量正确才替换文件，若访问失败不会改写旧目录。随后人工审查 diff，运行 build/tests，补齐头像、别名、跨服同名匹配，再走 PR。**本次未成功从执行环境实时获取国服官方完整列表**，新英雄与同名不同角色需要人工复核。
- 国际服原有英雄资源、Hero Sync、旧编号/本地头像路径保持不动；`/api/heroes` 默认返回国际服名单，`/api/heroes?pool=cn` 返回当前国服候选。
- Auto BP 图像模板及结算固定坐标源自国际服画面：国服独有英雄尚没有已训练的识别模板，国服/5 Ban 截图的额外 Ban #5 区域也需要手动实机校准。**不能因 Control 显示国服英雄池就认为 CN 自动 BP 已完成验收**。没有可信模板时使用手动输入，模拟器和 OCR 结果须分开核对。
- 0 Ban 不会录入空 Ban 阶段；空 Ban 操作仅在实际 Ban 阶段出现。5 Ban UI、Simulator 与 20 个可校准槽位（双方各 5 Ban + 各 5 Pick）一致；原前四个 Ban ROI 保留用户既有预设，第五个 Ban ROI 必须现场校准。

## 测试与回归矩阵

对 `global`、`cn` 两个目录和 `0–5` Ban 分别确认：设置/保存/刷新、每队 Ban 和 Pick 的数量与先后、红方先手、跳过 Ban、撤销/下一局/提交历史、选人列表过滤、重复英雄/全局历史限制、模拟器的 Ban #5、OBS 横排/竖排裁切、识别窗口预设迁移与低置信度人工回退。

软件自动化测试结果与独立真实环境测试分别记录于 [验证历史](../validation/history.md)。**国服实际游戏 UI、2026-10 实时国服完整名录、真实第五 Ban 画面、国服 10 人测试与 OBS 不在本次自动 CI 的验收范围内。**
