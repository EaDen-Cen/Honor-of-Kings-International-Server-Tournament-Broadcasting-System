# 可停靠导播工作区

收起设置面板后，仍可从「窗口」重新打开本地空间预览。在保留期限和来源凭据核对完成后执行清理。[空间维护操作](storage-maintenance.md)

Control 的真实业务面板使用 FlexLayout 0.8.17（与当前 React 18 相容）：比赛/BP 预览、BP 与识别、玩家、GHUD、OBS、赛后、MVP 投票、设置中心、恢复、英雄历史。设置中心集中 AI、Discord 和 OBS 凭证配置，原有比赛和英雄图片编辑继续使用现有入口。

1. 拖动标签标题到蓝色提示区域：窗口边缘或面板边缘拆分停靠，标签中央组合成选项卡。
2. 拖动分隔条改变宽高；双击标签栏最大化/还原。关闭标签只隐藏界面，从「面板列表」重新打开。
3. 切换默认、BP、局内、赛后分析、OBS 导播预设；输入名称「保存布局」可保存最多 10 个自定义预设，同名覆盖。「恢复上一次布局」可撤销最近的布局切换、拖动或关闭；该撤销历史只在当前页面会话保留。
4. 布局变化自动保存在当前浏览器/网站 origin，下次打开恢复；「恢复默认」只改布局，不重置比赛。未知版本、损坏或非法布局回退默认。
5. 操作指南中的导航先打开目标标签及折叠工具。小于等于 900px 用面板选择器切换工具，BP 与监看保持纵向同屏；回到桌面宽度恢复停靠布局。

关闭/隐藏面板不会停止已开启的识别任务。需要停止识别请使用对应面板的停止按钮；离开 Control 页面才按组件原有清理规则释放请求/监听器。比赛状态仍由服务器和 useMatch 管理。稳定 portal 容器只移动 DOM，不重挂业务组件，因此布局变化保留输入草稿和采集流。

布局存储键 `hok-dock-workspace-v1`，格式 `{version:1,preset,layout}`；自定义预设存于同名前缀 `-presets`。不包含比赛数据或 API Key。存储不可用时显示提示但仍能操作。

本机 Control 每 5 秒将已变化的布局、场景映射、音频目标和识别区域白名单备份到本地安全设置文件；同一浏览器优先保留现有值，浏览器缺少值时可从本地备份补回并刷新一次。凭证始终不进入浏览器存储。服务器备份失败会显示提示；最近 5 秒尚未备份的修改，在同一浏览器仍保留，但不能保证换浏览器恢复。自动切镜授权不持久化。

本次视觉使用静态海军蓝渐变、青色交互、金色结果和红蓝阵营标识，无循环粒子或大背景视频。面板最小 240×160；窄屏按所选工具显示，BP 保留纵向同屏，未新增依赖，也不擅自加载外部游戏图片。

键盘可访问工作区选择器、保存、面板菜单及原有 BP 快捷键。隐藏的英雄面板不会截获快捷键。拖拽与分隔条为鼠标交互；不提供跨浏览器窗口弹出（避免采集生命周期跨窗口）。

库选择依据：[FlexLayout 官方项目](https://github.com/caplin/FlexLayout)。锁定版本避免未经测试的 API 升级；布局序列化与业务组件保持独立。生产长时间内存稳定性仍需实机浸泡测试。


## 桌面菜单与网页内浮动（本轮开发）

顶部菜单栏约 38px，显示局数、阶段、服务器连接、OBS/REC 和未完成预检数量。文件菜单打开既有备份/恢复/导入/导出与访问设置；编辑提供 Undo、BP 纠错、选手分路与英雄归属入口；视图提供全屏、80–125% 工作区缩放和紧凑模式；窗口集中面板列表、预设、保存/删除自定义布局、默认/上次布局；帮助提供操作指南、快捷键和诊断。

赛前准备和操作指南是两个独立面板，通过窗口面板列表打开。关闭预检不表示检查通过，顶部仍显示人工未勾选和自动未通过项，紧急跳过仍显示未验证并保留原日志；新局重新计算。OBS 状态复用已有查询结果，不额外建立连接。

标签的「浮」按钮将同一 Portal 容器移到网页内窗口。拖动标题移动，右下角拖动调整大小（鼠标/触屏）；聚焦标题后方向键可移动。停靠返回 FlexLayout，关闭只是隐藏，采集与 OBS 任务保持挂载。窗口缩小时保持浮动标题可达。小屏可用当前面板选择器及窗口菜单的浮动操作。

菜单展开不推挤工作区。旧 v1 布局继续读取；保存时浮动面板会记为可恢复的停靠标签，刷新或载入预设后回到停靠状态，不保留临时浮动坐标。自定义布局最多十个，可删除当前选中的自定义布局；删除后恢复默认，不影响比赛状态。浏览器不允许全屏或存储时显示失败提示。
