# 可停靠导播工作区

Control 的真实业务面板使用 FlexLayout 0.8.17（与当前 React 18 相容）：比赛/BP 预览、BP 与识别、玩家、GHUD、OBS、赛后、恢复、英雄历史。设置和英雄图片编辑继续复用现有入口，没有空面板或第二套比赛状态。

1. 拖动标签标题到蓝色提示区域：窗口边缘或面板边缘拆分停靠，标签中央组合成选项卡。
2. 拖动分隔条改变宽高；双击标签栏最大化/还原。关闭标签只隐藏界面，从「面板列表」重新打开。
3. 切换默认、BP、局内、赛后预设；输入名称「保存布局」可保存最多 10 个自定义预设，同名覆盖。
4. 布局变化自动保存在当前浏览器/网站 origin，下次打开恢复；「恢复默认」只改布局，不重置比赛。未知版本、损坏或非法布局回退默认。
5. 顶部工作区导航会先打开目标标签及折叠工具。小于等于 900px 使用纵向响应式排列，回到桌面宽度恢复停靠布局。

关闭/隐藏面板不会停止已开启的识别任务。需要停止识别请使用对应面板的停止按钮；离开 Control 页面才按组件原有清理规则释放请求/监听器。比赛状态仍由服务器和 useMatch 管理。稳定 portal 容器只移动 DOM，不重挂业务组件，因此布局变化保留输入草稿和采集流。

布局存储键 `hok-dock-workspace-v1`，格式 `{version:1,preset,layout}`；自定义预设存于同名前缀 `-presets`。不包含比赛数据或 API Key。存储不可用时显示提示但仍能操作。

键盘可访问工作区选择器、保存、面板菜单及原有 BP 快捷键。隐藏的英雄面板不会截获快捷键。拖拽与分隔条为鼠标交互；不提供跨浏览器窗口弹出（避免采集生命周期跨窗口）。

库选择依据：[FlexLayout 官方项目](https://github.com/caplin/FlexLayout)。锁定版本避免未经测试的 API 升级；布局序列化与业务组件保持独立。生产长时间内存稳定性仍需实机浸泡测试。
