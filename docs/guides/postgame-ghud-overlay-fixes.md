## 赛后 Overlay 404 的根因与验证
PR #67 已在前端 `BroadcastApp` 中提供 `/overlay/postgame-compare` 和 `/overlay/game-progress`，但 Node 生产服务器固定路由白名单未登记这两项。当浏览器直接进入 `http://127.0.0.1:3001/overlay/postgame-compare?role=mid` 时，后端试图读取 `dist/overlay/postgame-compare`，返回「找不到页面或文件」。

修复：`server/uiRoutes.ts` 统一登记所有 SPA 内部 HTML 路由，前端仍复用已有 `dist/index.html` 和图形组件。步骤：更新仓库 → 在 `vite-project` 执行 `npm run build` → 停止旧进程并重启 3001 服务器 → 浏览器或 OBS 打开以下地址：
- `http://127.0.0.1:3001/overlay/mvp`
- `http://127.0.0.1:3001/overlay/postgame-compare?role=mid`（角色可改 clash/jungle/mid/farm/roam，雷达就在此页）
- `http://127.0.0.1:3001/overlay/game-progress`

这些图形只显示已有 `PostGameReport` 的真实数据；未准备报告、无经济点数或雷达双方指标不足时留空或明确提示。不是缺少 URL 的错误。MVP 英雄立绘改用完整画面适配，选手真实照片仍按肖像焦点裁切；没有可信官方评分时隐藏该统计卡，不计算伪官方评分。

## GHUD 遮挡与 OBS 顺序
1. OBS 的游戏画面源按精确游戏内容（非桌面边框）裁为 **1920×1080、16:9**，底层播放。
2. `/overlay/game-hud` 添加为上层浏览器源，设置相同宽高，不要二次拉伸。现在顶部（赛事条）、左右（选手名单）和底部（回放进度/技能原生 UI）全部用**不透明背景**遮挡，未由系统采集的等级/装备不造数据。
3. 小地图默认被不透明图形遮挡，显示「地图源未连接」。若正式比赛需要保留小地图：从同一游戏画面新增一份「地图局部裁切」源，在 OBS 叠到 HUD Browser Source 的**上方**，手动调整位置和尺寸；需避免露出地图原生边框。不同客户端、回放界面或手机窗口，顶部和底部遮挡高度可能不同，务必目视验证。
4. 实际赛事前检查蓝/红换边、比分变化、五名 ID、20:9/16:9 采集尺寸、技能栏、回放进度和队伍边栏；如有露出，须重新裁切游戏源或改 HUD mask 几何。遮挡是图层结构，不等于从游戏中提取原生 UI 数据。

## GHUD OCR 的七字段校准
1. Control →「局内 HUD」→「GHUD 顶栏识别」；选择共享游戏窗口。截图仅可做离线验证，不能启用截图自动播出。
2. 先核对游戏实际内容上下边界；默认 **顶部偏移 0**，不得根据窗口下方多出的回放控件自动猜测。非严格 16:9 内容请手动调偏移或先在游戏捕获源裁好。
3. 点击「预览当前帧」，在预览区域选择 **游戏时间、蓝/红方人头、蓝/红方经济、蓝/红方推塔**七个字段，然后拖框只包围数字；也可直接填以 1920×1080 为基准的 x/y/宽/高。
4. 按「保存选框并确认可采样」后，手动采样两次，逐行检查 OCR 原文本、置信度及已经核验的字段。数据过期、不合理跳变、两帧不同画面 ROI、时间未前进或人工冻结均不应写入正式 UI。
5. 只有确认真实 UI 上七个数字可靠后，才可选择每 5 秒轮询或自动播出。切换共享源、调整顶部偏移或修改 ROI 会自动关闭自动播出，必须重新预览并确认。七个 ROI 的草稿存放在**本浏览器** localStorage，不随服务器自动备份、跨端同步。
6. 若游戏 UI 改版、语言不同、图标遮挡、人物头像闪动或经济缩写文字与校准预期不一致，及时取消自动发布，保留人工录入并使用原冻结/Undo。

## 边界、测试和下一步
单元测试覆盖后端路由表、ROI 数量/边界/重叠、跨 ROI 配置无法合并、静止回放时钟与既有时间趋势。生产 build/ESLint/CI 的绿灯不能证明真实十人比赛和 OBS 画面没有漏边。必须由导播提供相同观战界面的完整截图或录屏来确定所有 HUD 原生部件是否被遮挡；官方赛事图只作布局参考，不表示当前版本能读取其内部数据。


**本次回归纠正：** 合成 HUD 真实数值样本确认，蓝方经济在纯 OCR 模式下曾被误读为十倍（1.5K→15.0K）。因此保留针对含明显青色原生 HUD 强调色的自适应背景抑制；没有青色强调色时使用原图，不对新 UI 强制蓝方遮罩。任何模式仍需真实七字段校准、两次检测与人工审核，这不构成官方 UI 通用识别保障。


**默认全遮挡安全区（1920×1080）：** 顶部 146 px，左侧 210 px、右侧 250 px，中央底部 280 px，地图占位覆盖左上 450×395 范围（含顶部遮罩）。这些数值对应用户提供的回放窗口比例，是待现场校验的参考，不是任意游戏客户端都适用的固定官方布局；不同 UI 需要按实际画面调整。
