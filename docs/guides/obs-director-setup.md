# OBS 导播台：连接与联动

[文档索引](../README.md) · [比赛操作](operator-guide.md)

本轮加入 OBS 5.x 本地连接、人工一键场景预设、阶段音量/渐变和录制健康读取。开播检查使用服务器保存的选手核验及阵容状态，原来的浏览器勾选已移除。真实 OBS 长时间、音画同步与双场比赛仍须现场复测。

## 第一次连接

1. 在运行 HOK 后端的同一台电脑打开 OBS。进入 OBS 的「工具 → WebSocket 服务器设置」，启用服务器并开启密码认证。
2. 在 Control 顶部的「OBS 导播台」展开「OBS 连接与高级绑定」。填写本机地址，通常为 `ws://127.0.0.1:4455`，输入 OBS WebSocket 密码，点击「保存并连接 OBS」。
3. 看到已连接后，检查正在播出的场景、录制/直播状态是否与 OBS 一致。输入错误密码或 OBS 未启动时，面板会显示原因，比赛采集和 BP 可以继续使用。
4. 在场景绑定中，从 OBS 返回的已有场景中选择赛前、BP、比赛、暂停、结算、五个对位、MVP 和安全画面。只设置本场会使用的预设即可。
5. 将游戏、解说、背景音乐和音效绑定到各自实际音源；需要一键改变音量的阶段，再设置该阶段的目标音量、静音及渐变。未绑定音源时，取消对应阶段的音量动作，避免按钮因缺少音源而失败。
6. 保存设置。修改场景/音源绑定与警告线不会切断当前连接；修改连接地址、密码或移除密码后，需要重新连接并核对。

OBS 28 起内置 5.x WebSocket；协议提供场景、音源和录制状态查询。本程序使用社区维护的 `obs-websocket-js` 5.x 客户端。参考 [OBS WebSocket 项目](https://github.com/obsproject/obs-websocket) 和 [客户端文档](https://github.com/obs-websocket-community-projects/obs-websocket-js)。

## 有实际作用的开播检查

「核验 / 调整选手 ID」会跳到真实的 Player ID 面板。先检查双方 P1–P5 对应的选手：可以应用可信 OCR 排列、人工交换顺序，或确认当前排列。操作须由服务器保存后才显示核验完成，刷新和其他导播页面可以读到相同结果。

「进入比赛」预设会检查十名选手 ID、双方五个分路、已保存的 P1–P5 核验、本局 BP 完成状态及合法最终英雄归属。未通过时按钮旁列出问题和处理入口；后端也执行相同检查，并在渐变后、切场景前再检查一次，防止处理过程中换人或切局。

改名单、分路、P1–P5、换边或进入下一局后，旧核验失效。原有 BP、人工录入、比分、采集、OBS 自身操作继续独立工作；检查用于本程序的比赛场景联动，不代替裁判或导播检查真实游戏画面。

## 比赛中操作

- 点击阶段按钮，按已保存的设置调音并切换真实 Program 场景。成功需要 OBS 回执和实际读数一致；单纯发送请求不会显示成功。
- 五个对位预设分别绑定五个固定角色页面对应的 OBS 场景；本程序不擅自新建或改写 OBS 场景与 Browser Source。
- 背景音乐支持目标音量、0 / 1.5 / 3 秒渐入渐出、一键静音及取消渐变。安全画面与音乐静音可接管进行中的动作；安全预设仅操作已配置的音源，不停止录制或直播。
- 在 OBS 中人工切场景或调绑定音源时，旧的冲突动作取消，不会随后抢回原目标。部分步骤已执行时不会擅自回滚，请核对实际状态后决定下一步。
- 超时、断线显示「待核对」，恢复连接先读取实际状态，不自动重放旧命令。刷新或断开 Control 不会结束 OBS 录制/直播。
- 音乐播放源先在 OBS 中准备好；本轮控制音量、静音和渐变，未加入独立播放器、歌单或自动重播。

## 录制与磁盘提醒

录制/暂停/直播状态与时长来自 OBS。录制由开启变为停止时，面板保留告警；检查 OBS 错误提示与实际文件。断线时录制状态显示未知，不继续把旧读数当作正在录制。

优先读取 OBS 的录制输出目录，再由本机 Node 查询该目录所在卷的可用空间；OBS 无法提供目录时，可在高级设置中指定绝对本地目录，并标记为手动指定。剩余时间按近期录制文件增长速率估算，尚无足够样本时不显示虚构时长。容量线与时长线可调整，低容量或路径读取失败会提示。

程序只提醒，不自动删素材、更改录制目录、启动/停止录制或结束直播。即使电脑显示有空间，仍需在 OBS 中检查编码器错误、录制暂停与文件可写性。

## 保存和权限

OBS 连接密码只保存在后端数据目录独立的 `obs-connection.local.json`，API 只返回「是否已保存」，不回显密码；不会写入浏览器存储、比赛 MatchState、比赛导出或恢复备份。迁移机器需单独配置 OBS。地址仅支持本机回环地址；远程本地 Agent 接入仍在规划中。

只有 Control 凭据可读取 OBS 配置、录制本地路径或发控制命令；Caster 与 Overlay 没有这些权限。本轮没有提供停止录制、停播、删除文件或任意 OBS 请求接口。

损坏的 OBS 配置会保留原文件，并禁用 OBS 控制、在界面显示错误；不会阻止比赛服务启动。修正设置后可重新连接。软件验证与实机验收区分记录于 [验证历史](../validation/history.md)。
