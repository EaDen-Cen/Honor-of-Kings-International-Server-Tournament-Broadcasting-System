现有素材路径、AE 工程是否可用、能否导出无字底片尚待确认。

## 可落地的调整方向

1. 若转场仅显示 A队 VS B队，没有蓝红方、比分和局数，可采用整个系列赛固定的队伍展示顺序；
   换边只更新 BP/比分界面。若明确标记了红蓝方，则需要改一次原工程。
2. 对当前媒体源方案：由 AE 一次导出无字动画底片，固定文字可用上层 Browser Source 显示队名和 Logo；
   若文字有运动、遮罩或严格时序要求，在同一 Browser Source 内统一组合视频、队名和 Logo。
   网页从服务器读取比赛数据，播放开始时固定本次画面，避免动画中途换边导致跳字。
3. 初期将其用作独立“对阵卡”场景，导播手动切入/切出；不要求实现 OBS 自动切场景。
4. 普通场景内 Browser Source 不能天然覆盖不透明的原生 Stinger；不可把两者直接叠加当成完成方案。
5. 已写入成片的视频文字无法靠改数据可靠删除；需要 AE 源工程或无字底片。
6. 将来换边操作须交换队伍身份对应的队名、Logo和系列赛比分，不能只交换队名或让胜场留在旧颜色上。
   系列赛队伍身份和单局蓝红方应分别管理，具体实现排在实际接入阶段。
