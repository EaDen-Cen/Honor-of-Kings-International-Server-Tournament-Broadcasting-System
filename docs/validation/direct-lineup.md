# BP 直接编辑与本局阵容验证

## 分阶段实现

1. 复用 Store、PlayerSlotOrder、Assignments 和报告 rowId，增加本局分路与确认状态。
2. BP 原监看头像接入纠错选择器，玩家面板提供五路卡片、英雄交换、选手换路、预览确认及历史局入口。
3. 检查报告、MVP、Caster、Overlay，验证档案兼容、系列隔离、自动识别晚到、鼠标和触屏输入。

## 验证记录

基线浏览器回归 105 项通过。本次新增 BO1/3/5 Store 回归验证了个人数值、分路、英雄归属及 Pick 次序独立，覆盖提交、历史修正、重启与 Undo。自动角色推断保持人工确认，未提供实战识别准确率。

完整 build、lint、unit 与浏览器结果在本分支验证完成后补充。首轮浏览器定位到停靠区滚动导致拖动目标不可见，已加入五路紧凑排布并在拖动测试中验证来源和目标均在视口内。

## 现场验收

- 使用真实 BP 画面纠正一个早期锁定头像，确认阶段不前进，观察 Overlay 更新。
- BP 完成后交换选手实际分路，记录两名选手身份、英雄与个人数据，再独立交换英雄。
- 在 BO3/5 第二局采用不同分路，然后修正第一局，逐页核查 MVP、五路对位及当前局。
- Windows 鼠标与实际平板分别操作点击替代和拖动，检查较窄停靠区、滚动、误触取消、断网与恢复。
- 人工确认时保留正在进行的 OCR 请求，核查其晚到结果无法覆盖本局人工阵容。

以上现场项目尚未执行，需真实设备与赛事样本。
