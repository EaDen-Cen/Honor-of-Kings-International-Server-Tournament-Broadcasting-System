## BO3 隔离彩排

三局依次：完成合法 BP → 未提交时验证 game 建议 → 提交并创建当前局报告 → 验证 postgame 建议 → 保存已核验十人字段与经济时间线 → 自动轮播对抗/中/发育/打野/游走/经济 → 停止 → 下一局；最终比分 2:1、三份不可变 BP 历史。模拟 OBS 响应，不执行真实切镜。轮播时钟采用真实的每页 2 秒测试时长；投票 3 分钟恢复由可控时钟测试独立覆盖，不伪称真实 Discord 3 分钟彩排。

## 2026-10-30 跨局报告编辑回归
