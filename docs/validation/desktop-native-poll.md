## API 依据

[Discord Poll Create Request](https://docs.discord.com/developers/resources/poll) 定义小时整数 duration、最多十个答案、问题 300 字符及答案 55 字符；[Execute Webhook](https://docs.discord.com/developers/resources/webhook#execute-webhook) 支持 poll 与 wait 返回发送结果。实际请求以本次真实频道回读为补充证据。

## 剩余边界

- 普通 Webhook 不能提前关闭原生 Poll；三分钟是软截止，不是严格停票，也没有可靠三分钟票数快照。需要严格停票时选择独立网页模式。
- 自动鼠标/触屏测试不代表真实平板硬件或完整赛事彩排。OBS/录制与采集持续性使用隔离测试，不冒充现场设备验收。
- 回滚前保留比赛与独立投票/通知存档。旧服务不认识新增原生记录，不能通过删除记录来恢复旧版或重发。
