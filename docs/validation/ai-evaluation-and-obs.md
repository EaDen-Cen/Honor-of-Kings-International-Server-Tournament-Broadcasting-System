# AI 配对评测与 OBS 操作改进验证

日期：2026-10-21。

## 本次范围

- 模拟器新增英雄裁图配对评测：本地与 AI 融合共用输入和正式融合规则，统计准确率百分点、纠正/退化、P95、无有效 AI 结果与请求失败，支持停止和 JSON 导出。
- AI 正确答案仅在浏览器评分；后端只接收图片、英雄池和裁图形状。不改写比赛状态，不切换 AI 配置，不执行 OBS 指令。
- OBS 增加返回上一确认场景、切镜等待反馈、请求超时与失败后的实际状态查询；指令发出前的旧轮询不得覆盖确认结果。
- lint 排除本地运行数据目录，避免扫描浏览器用户配置中的第三方扩展。

## 自动验证

- `npm test`：311 项，309 通过、2 跳过、0 失败。新增覆盖弱识别补充、可信冲突、强本地保留、无效答案回退、禁用 AI、只读轮询不再次发请求及配对统计。
- `npm run build`、`npm run lint` 通过。构建仍有大于 500 kB 的包体提示。
- AI 评测浏览器测试覆盖上传、真值不进请求、评分、失败提示、导出与窄屏；OBS 浏览器测试覆盖手动切镜、返回上一场景和音频淡变；另测评测端点权限和输入验证。
- 新增/修改核心 TypeScript 文件的格式检查通过。全仓 `format:check` 仍报告 39 个既有文件格式问题，没有对这些文件做批量格式化。

## 证据边界

浏览器测试使用模拟 AI/OBS 响应，截图中的 100% 仅为测试断言数据，不能作为真实模型提升结论。没有调用真实付费模型，也没有连接用户赛事机 OBS。首次沙箱浏览器测试因回环网络 EACCES 未进入测试；获准权限运行后可以验证页面。损坏的初版测试 PNG 已替换为 sharp 生成的有效图片。

真实验收请使用 [AI 操作说明](../guides/ai-recognition.md) 中的独立截图集，在自己的模型配置上运行；OBS 仍需进行现场连接、断线恢复和长时间彩排。静态 Top-1 提升不等同于连续视频的采用率、人工修正时间或整条广播链路的延迟改善。
